# langues_de_specialite
### Exploration d’OpenEdition Journals — 12 novembre 2026

J’ai exploré trois revues : Lidil, Traduire et GLAD!. J’ai été particulièrement intéressé(e) par la féminisation des noms de métiers, les choix lexicaux dans la traduction et les particularités des sociolectes. J’ai parfois hésité dans le choix des phénomènes linguistiques à observer et dans la formulation des questions de recherche. Je devrai poursuivre la lecture des articles, vérifier les exemples et examiner d’autres textes pour voir si les phénomènes observés sont récurrents.
